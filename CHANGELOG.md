# Changelog

This file records user-visible changes for public alpha releases.

## [0.1.0-alpha.1] - Unreleased

### Added

- Browser-local music mathematics lessons covering the current eight curriculum domains.
- Optional local microphone and browser-decodable audio analysis in designated critique lessons.
- Local learning portfolio storage and lesson hash routes.
- Constrained migration of valid version 1 ensemble records into current
  lesson factors, with explicit unit conversion and protocol separation.

### Known limitations

- The application is alpha software. Compatibility and behavior may change;
  migration support beyond the current version 1 to version 2 copy is not
  guaranteed.
- Audio-derived results are uncalibrated descriptive observations, not performance assessment or complete transcription.
